Paramètres de l'IA

Clé Agnes AI

Active l'Agent IA, les images haute qualité (~10 s), Image → Image et la vraie vidéo IA. Clé gratuite sur platform.agnes-ai.com. Elle reste uniquement sur cet appareil.

Quand la file vidéo d'Agnes est pleine, l'app réessaie pendant ce temps puis crée un montage animé avec des images Agnes.

Serveur GPU (optionnel)

Lance notebooks/DianaLuxe_GPU.ipynb sur Google Colab ou Kaggle (GPU gratuit) pour un modèle vidéo open-source sans file d'attente.

Préférences

Aide & support

Comment ça marche ?

Avec une clé Agnes : l'Agent IA discute avec toi, les images sont créées en ~10 s et les vidéos par l'IA vidéo d'Agnes. Si Agnes est saturée, l'app monte automatiquement une vidéo animée (mouvements de caméra, transitions, musique) à partir d'images IA.

Sans clé ?

Tout marche quand même avec Pollinations (gratuit) : 1 image toutes les 45 s, donc c'est plus lent.

« Agnes est saturée »

La file d'attente vidéo gratuite d'Agnes est souvent pleine. L'app réessaie toute seule toutes les 30 s. Augmente la patience dans Paramètres de l'IA, ou utilise le serveur GPU gratuit (Colab/Kaggle).

Où sont mes créations ?

Dans la Bibliothèque, enregistrées sur cet appareil uniquement. Pense à les télécharger.
