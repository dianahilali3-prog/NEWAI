Paramètres de l'IA

Clé Agnes AI

Active l'Agent IA, les images haute qualité (~10 s), Image → Image et la vraie vidéo IA. Clé gratuite sur platform.agnes-ai.com. Elle reste uniquement sur cet appareil.

Quand la file vidéo d'Agnes est pleine, l'app réessaie pendant ce temps puis crée un montage animé avec des images Agnes.

Hugging Face : Qwen-Image + vidéo IA LTX (open source)

Qwen-Image (Alibaba) et LTX-2.3 / LTX-Video (Lightricks, vidéos IA jusqu'à 10 s avec le son) sont open source et tournent gratuitement sur les GPU de Hugging Face, avec un quota de temps GPU par personne. Crée un compte gratuit sur huggingface.co, puis Settings → Access Tokens → « Create new token » (type Read) et colle-le ici. Le token reste sur cet appareil.

Serveur GPU (optionnel)

Lance notebooks/DianaLuxe_GPU.ipynb sur Google Colab ou Kaggle (GPU gratuit) pour un modèle vidéo open-source sans file d'attente.

Aide & support

Comment ça marche ?

Avec une clé Agnes : l'Agent IA discute avec toi, les images sont créées en ~10 s et les vidéos par l'IA vidéo d'Agnes. Si Agnes est saturée, l'app monte automatiquement une vidéo animée (mouvements de caméra, transitions, musique) à partir d'images IA.

Sans clé ?

Tout marche quand même avec Pollinations (gratuit) : 1 image toutes les 45 s, donc c'est plus lent.

« Agnes est saturée »

La file d'attente vidéo gratuite d'Agnes est souvent pleine. L'app réessaie toute seule toutes les 30 s. Augmente la patience dans Paramètres de l'IA, ou utilise le serveur GPU gratuit (Colab/Kaggle).

Installer l'application

Sur iPhone : ouvre le site dans Safari → bouton Partager → « Sur l'écran d'accueil ». Sur Android : menu de Chrome → « Installer l'application ». Éclat Ai s'ouvre alors en plein écran, comme une vraie app.

Vidéos IA open source, voix off, détourage

Avec ton token Hugging Face, les vidéos passent d'abord par LTX-2.3 (vraie vidéo IA, avec le son). Dans Options avancées d'une vidéo, ajoute une voix off en français (générée sur ton téléphone). Sur une image, « Plus » → « Détourer » enlève le fond.

Qwen-Image et Nano Banana

Qwen-Image (Alibaba) est open source et gratuit sur Hugging Face avec un quota GPU par personne : ajoute ton token Hugging Face gratuit dans Paramètres de l'IA. Nano Banana 2 (Google) n'est pas open source et n'a pas d'accès gratuit officiel : il n'est donc pas intégré.

Studio en lot

Jusqu'à 30 créations, chacune avec son prompt. Une idée par ligne, « vidéo: » devant pour une vidéo, « @Prénom » pour un personnage. Tout se génère en même temps.
